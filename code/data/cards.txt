# CSC301 Monopoly - "Capital Circuit" - CARD FILE
# Format (brief Appendix B.2): <deck>|<id>|<text>|<effect>|<argument>
# Effects: MOVE_TO <square name> | MOVE_BY <int> | NEAREST TRANSIT |
#          COLLECT <amt> | PAY <amt> | PAY_EACH <amt> | COLLECT_EACH <amt> |
#          GO_TO_JAIL | JAIL_FREE | REVERSE (T1) | RECALL (T7)
#          (no argument -> line ends with |)
# Each deck is shuffled once at game start (seeded Random), then used as a
# LinkedQueue: draw = dequeue, apply, enqueue at back (JAIL_FREE kept by the
# player until used, then enqueued at the back of its own deck).
# Design rule: no card move ends on a CHANCE or COMMUNITY square, so landOn()
# recursion depth is at most 2 (card square -> destination square).
# Twist cards (Group 4): REVERSE (T1) reverses the turn queue; RECALL (T7)
# brings the last 3 cards of the same deck to the front. One of each per deck.
# ============================================================================
